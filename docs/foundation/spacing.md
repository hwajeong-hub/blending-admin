# Spacing

> 패딩·간격·마진에 쓰는 간격 토큰.

## 개요

간격은 **4px 그리드**입니다. 토큰 이름의 숫자에 4를 곱하면 px입니다 (`--spacing-4` = 16px, `--spacing-1-5` = 6px).
작은 쪽(2·4·6)은 촘촘하게, 그 위로는 4의 배수로 커집니다. **스케일 밖 값은 쓰지 않습니다.**

## 스케일

| CSS 토큰 | px | CSS 토큰 | px |
|---|---|---|---|
| `--spacing-0` | 0 | `--spacing-6` | 24 |
| `--spacing-0-5` | 2 | `--spacing-7` | 28 |
| `--spacing-1` | 4 | `--spacing-8` | 32 |
| `--spacing-1-5` | 6 | `--spacing-10` | 40 |
| `--spacing-2` | 8 | `--spacing-12` | 48 |
| `--spacing-3` | 12 | `--spacing-16` | 64 |
| `--spacing-4` | 16 | `--spacing-20` | 80 |
| `--spacing-5` | 20 | | |

`--layout-gutter`(Contents 좌우 여백)는 데스크톱 `--spacing-10`(40), 모바일 `--spacing-4`(16)입니다.

## 쓰는 곳

| 값 | 토큰 | 쓰는 곳 |
|---|---|---|
| 4 | `--spacing-1` | 버튼 아이콘-라벨, 페이지 번호 사이, 사이드바 메뉴 사이 |
| 6 | `--spacing-1-5` | 툴바 버튼 사이, 라벨-인풋 |
| 8 | `--spacing-2` | Page Header 제목-설명, Controls, Chip 사이, CTA 버튼 사이, 필터 행, 페이지 화살표 묶음, 사이드바 메뉴 좌우 |
| 12 | `--spacing-3` | 인풋·버튼·셀 좌우 패딩, 요약 항목 제목-값 |
| 16 | `--spacing-4` | 툴바 좌측, 표 블록 세로 간격, 모바일 좌우 여백, 순위 보고서 요소 간격, 요약 항목 좌우, 탭 아래 섹션 위 |
| 20 | `--spacing-5` | 모달 좌우 패딩·요소 간격, 모달 폼 필드 간격(시간·슬롯 모달 `.is-compact`) |
| 24 | `--spacing-6` | 폼 필드 간격, 요약 바·필터 카드 패딩, 요약 섹션 위 |
| 32 | `--spacing-8` | 콘텐츠 섹션 위, 모달 위아래 |
| 40 | `--spacing-10` | **Contents 좌우 여백**, 콘텐츠 섹션 아래 |

> **2026-11-06 정리**: 그리드 밖 값 `10 → 8`(사이드바 메뉴 좌우, 페이지 번호·CTA·필터 행·프로필·달력 표시줄 간격, 파일선택 버튼)과 `30 → 32`(콘텐츠 섹션 위, 모달 위아래)로 맞췄습니다. `34`는 간격이 아니라 테이블 헤더 높이(`--table-head-h`)입니다. 로그인 카드 padding `48 30`도 `48 32`로 맞췄습니다.

## 사용 예

```css
.toolbar { gap: var(--spacing-1-5); }
.modal { padding: var(--spacing-8) var(--spacing-5); gap: var(--spacing-5); }
.box-helper { margin-top: calc(-1 * var(--spacing-1)); }   /* 음수는 calc로 */
```

화면마다 다른 여백은 인라인 스타일 대신 수정 클래스로 만듭니다.

```css
.modal-body.is-compact { gap: var(--spacing-5); }     /* 필드가 많은 모달 */
.tabs + .section { padding-top: var(--spacing-4); }   /* 탭 바로 아래 섹션 */
```

## Do / Don't

| | 규칙 |
|---|---|
| **Do** | 묶음 안쪽은 작은 간격(4–8), 묶음 사이는 큰 간격(16–24)으로 나눠 경계 없이도 묶음이 보이게 한다 |
| **Do** | 패딩은 감싸는 쪽이 갖고, 안쪽 요소는 바깥 마진을 두지 않는다 |
| **Do** | 스케일에 없는 값이 필요하면 디자인을 다시 본다 |
| **Don't** | `10px`, `30px`처럼 그리드 밖 값을 쓰지 않는다 |
| **Don't** | 한 컴포넌트 안에서 토큰과 px를 섞지 않는다 |
| **Don't** | 인라인 `style="padding-top:16px"`로 여백을 고치지 않는다 |
